Integration

Copy the CSS between the BEGIN and END markers into the shared stylesheet, and the markup between the MASTHEAD MARKUP comments into the layout. The component reads only --container*, --espresso, --vellum-*, --coffee-*, --oxblood, --gold, --card-line and --radius-pill — so every surface must be on the canonical token set for it to render identically.

Every surface writes the badge through this component's API. The #mhCartBtn / #mhCartCount IDs that appear inside Print Shop carry data-owner="masthead-component" and exist only so that mock renders — a page script must not query them directly.
