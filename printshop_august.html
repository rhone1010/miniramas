Shipping There aren't separate shipping SKUs. Prodigi treats shipping as an order-level shippingMethod, and the Quote API calculates what's actually available and what it costs for the destination + products. The supported API values are: Litenco Prodigi API value Economy Budget Standard Standard Priority StandardPlus Express Express Overnight Overnight Not every method is available for every product/destination. The Quote endpoint can return all available shipping quotes when you don't specify a shipping method. That's actually ideal for Litenco. Don't maintain a shipping SKU table. At checkout: Prodigi SKU + quantity + destination → Quote API → available shipping choices + actual costs Prodigi also consolidates shipping intelligently. For multiple canvases/frames, the largest item gets the main shipping charge and subsequent pieces generally get a smaller "+1" charge. Rolled prints often use a flat-rate model. So I think the Litenco 1:1 catalog should ultimately be just 24 product SKUs, with shipping dynamically quoted. Clean, manageable, and mercifully devoid of 173 nearly identical print choices.
